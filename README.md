Curated List of SaaS Products & Open-Source GitHub Projects
Focused on Investment Portfolio Management, Wealth Management, Performance Analytics, Portfolio Accounting, Asset Allocation, Reporting & Investment Intelligence
Last updated: September 2026

This repository tracks notable SaaS/hosted platforms and open-source projects for Portfolio Management Systems (PMS). These tools help wealth managers, registered investment advisers, family offices, institutional investors, and individual investors track holdings, transactions, valuations, performance, allocations, benchmarks, taxes, cash flows, and investment risk.

Typical capabilities include multi-account portfolio aggregation, portfolio accounting, transaction management, performance measurement, time-weighted and money-weighted returns, asset allocation, rebalancing, benchmark comparison, tax-lot tracking, client reporting, investment analytics, financial planning, and portfolio visualization.

Examples include Morningstar Direct, Addepar, Orion, Envestnet, Tamarac, FundCount, AssetBook, PortfolioCenter, Croesus, and Captools (the category leaders).

Open-source emphasis: This section is heavily expanded with major open-source portfolio trackers, wealth-management applications, investment accounting systems, quantitative research platforms, double-entry accounting tools, financial analytics libraries, market-data frameworks, portfolio optimization engines, and self-hosted investment dashboards. Fully integrated open-source replacements for enterprise wealth-management suites remain relatively limited, but the open-source ecosystem provides many powerful components for building transparent and self-hosted portfolio management systems.

Additional Strong Open-Source Options

Complete portfolio trackers: Ghostfolio, Wealthfolio, LibreFolio, Portfolio Performance, rotki, and newer self-hosted portfolio projects provide the closest direct open-source alternatives for portfolio tracking and investment analysis.

Investment accounting: Beancount, Ledger, hledger, Fava, GnuCash, and Money Manager Ex can provide transparent transaction records, investment accounting, cost tracking, and financial reporting.

Portfolio optimization: PyPortfolioOpt, Riskfolio-Lib, PortfolioLab, NumPy, SciPy, and quantitative finance libraries provide strong foundations for asset allocation and portfolio optimization.

Quantitative portfolio research: QuantConnect Lean, Zipline, Backtrader, vectorbt, QSTrader, bt, FinRL, and other frameworks can support systematic portfolio construction and backtesting.

Performance and risk analytics: Pyfolio, empyrical, ffn, statsmodels, QuantLib, OpenGamma Strata, and pandas can provide portfolio statistics, risk metrics, return analysis, and advanced financial calculations.

Market-data integration: OpenBB, yfinance, pandas-datareader-compatible projects, exchange APIs, and community data connectors can supply market prices and financial information.

Portfolio reporting: Apache Superset, Metabase, Grafana, Jupyter notebooks, and Python visualization libraries can create self-hosted portfolio dashboards and reporting systems.

Portfolio databases: PostgreSQL, DuckDB, SQLite, TimescaleDB-compatible systems, and Parquet-based data stores can manage transactions, positions, valuations, and historical market data.

Tax and transaction workflows: Plain-text accounting systems, transaction importers, broker CSV parsers, and custom Python pipelines can provide transparent alternatives to proprietary portfolio accounting workflows.

AI-assisted portfolio analysis: Open-source language models, Ollama, local embedding models, Python analytics libraries, and agent frameworks can be combined to build private portfolio analysis and reporting assistants.

Many community projects exist for portfolio trackers, investment dashboards, stock analysis, ETF analytics, crypto portfolio management, broker integrations, asset allocation, and personal wealth tracking.

Frameworks for building custom systems: Combine LibreFolio, Ghostfolio, or Wealthfolio for the portfolio-management interface with PostgreSQL or DuckDB for persistent financial data. Use OpenBB and yfinance for market data and research, Beancount or Ledger for transparent investment accounting, and PyPortfolioOpt + Riskfolio-Lib for portfolio construction and optimization.

For quantitative strategies, integrate QuantConnect Lean, vectorbt, Backtrader, or Zipline. Use Pyfolio, empyrical, ffn, and statsmodels for performance and risk analysis. Automate market-data and valuation workflows with Apache Airflow or Prefect, and create dashboards using Apache Superset, Metabase, or Grafana.

This modular architecture can provide a powerful, transparent, and self-hosted alternative for portfolio tracking and analytics. Enterprise commercial systems may still provide more mature institutional data feeds, regulatory reporting, tax-lot accounting, managed-account workflows, custodial integrations, and enterprise-grade client reporting.

Disclaimer

This is a community-curated list — not exhaustive and not an endorsement.

Portfolio-management and investment analytics software can contain incorrect market data, calculation errors, missing transactions, or inaccurate performance results.

Automated portfolio analysis and optimization should not be treated as personalized investment, legal, tax, or financial advice.

Historical investment performance does not guarantee future performance.

Users should independently validate portfolio calculations, benchmark definitions, corporate actions, tax treatments, and market data before making financial decisions.

Self-hosted open-source deployments require appropriate security, encryption, backups, access controls, and protection of sensitive financial data.

Open-source projects in this ecosystem often provide specialized portfolio tracking, accounting, research, optimization, or analytics components rather than complete turnkey replacements for enterprise portfolio-management platforms.
